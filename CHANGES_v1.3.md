# Shaplum Kids Games 1.3.0 — changes

This is a new build candidate, not an approved store release.

- Rebuilt toy-world home, game selection and level selection in the Android app using `PremiumWorld`, `PremiumModes`, `PremiumMap`, and `PremiumSuccess`.
- Kept all 8 games and all 120 local levels directly selectable; stars track progress.
- Rebuilt placement boards with larger sockets and toy pieces, more touch-friendly layouts and magnetic near-drop support.
- Easy placement supports tapping toys; dragging remains available.
- Removed image cropping from the new hero and game art, using `ContentScale.Fit`.
- Fixed the Arabic home heading from wrapping onto a second line on narrower phones.
- Preserves original app identifier, offline architecture, and English/Arabic/Portuguese localisation.
- Debug APK only until signing with original production key and review of child privacy.

Actual appearance and ease-of-play must still be checked on devices before publishing.
